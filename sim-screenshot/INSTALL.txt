PANDUAN CEPAT INSTALASI

1. Ekstrak ZIP ke C:\xampp\htdocs\sim-screenshot
2. Jalankan Apache dan MySQL dari XAMPP.
3. Buka http://localhost/phpmyadmin
4. Import database/db_organisasi.sql
5. Import database/upgrade.sql
6. (Opsional) Import database/demo-data.sql
7. Buka http://localhost/sim-screenshot/

PEMBARUAN VERSI ANIMASI RICH
- Untuk instalasi lama, cukup timpa file aplikasi dari paket update-only.

- Setelah update, tekan Ctrl + F5 pada browser.
